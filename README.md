## Description
A small multi-page site with a navbar that covers every task of the assignment.

| Page | Tasks |
| --- | --- |
| `index.html` | Task 0 (first script, console output, alert), Task 1 (variables & operators) |
| `dom.html` | Task 2 (change text), Task 3 (change styles), Task 4 (add/remove list items) |
| `events.html` | Task 5 (mouse events), Task 6 (keyup), Task 7 (calculator) |
| `todo.html` | Task 8 (To-Do app: add, delete, mark completed; tasks stored in an array) |

## How to run
1. Clone or download the repository.
2. Open `index.html` in a browser (no build step or dependencies).
3. Open the console (F12) to see the output of Task 0 and Task 1.

## Deploy
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
